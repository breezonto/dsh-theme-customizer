# Theme customizer

A DeepSeek Harness Web plugin that lets you customize the GUI theme from **Settings → Theme**.

## What it does

- **Wallpaper** — set a background image for the conversation area from an image URL, a data URL, or a local image file.
- **Wallpaper transparency** — control how strongly the wallpaper shows through (0–100%).
- **Global font** — change the interface and conversation font everywhere *except* the message composer (for example `Cambria`).
- **Composer font** — change the message composer font independently.
- **Accent color** — pick the primary brand color (primary buttons and brand accents) for the light and dark palettes separately.
- **Reset to defaults** — clear every setting at once.

## Notes

- Changes apply live and persist in the plugin configuration.
- The wallpaper is drawn behind the app surface (conversation area and sidebar); message, card, and panel surfaces keep their own backgrounds for readability.
- The global font is the same value as the built-in "Text font" appearance setting, surfaced here for convenience.
